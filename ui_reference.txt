. Overall visual style




Style: monochrome white/black/gray interface with restrained emerald and muted cyan accents.


Light mode: near-white page, white panels, charcoal text.


Dark mode: charcoal page, slightly lighter panels, near-white text.


Layout: one scrolling page with a sticky navigation bar.


Sections: overview, compression playground, analytics, architecture, footer.


Icons: outlined icons from Lucide React.


No purple: the token named --violet is actually neutral gray; its name does not reflect a purple color.

8. Animations used


One-time scroll reveal


.scroll-reveal {
  opacity: 0;
  transform: translate3d(0, 22px, 0);
  transition:
    opacity .7s cubic-bezier(.22, 1, .36, 1),
    transform .7s cubic-bezier(.22, 1, .36, 1);
  transition-delay: var(--reveal-delay, 0ms);
}

.scroll-reveal.is-revealed {
  opacity: 1;
  transform: translate3d(0, 0, 0);
}





Stagger delays: 0, 75, 150, 225, 300ms.


Trigger: IntersectionObserver with 0.08 threshold.


Observer margin: 0px 0px -30px 0px.


Each element reveals once, then stops being observed.


Applied to hero content, pipeline labels/nodes, section headings, workspace, result headings/panels, statistic cards, chart panels, and architecture cards.




Hero particles




Canvas contains 65 particles.


Radius: 1px, or 1.6px for every fourth particle.


Color: --particle.


Vertical movement: Math.sin(frame / 130 + i) * 5.


Render loop: requestAnimationFrame.


Canvas is behind content and ignores pointer events.




Other movement




Navigation uses browser smooth scrolling; no custom duration is specified.


Loading icon uses Tailwind animate-spin: 1-second linear rotation, repeating.


Radar and donut chart animations are explicitly disabled.


Bar and line charts retain Recharts’ default animation behavior.


The large metric numbers are static, not animated counters.




Reduced-motion support




CSS animations and transitions are disabled when prefers-reduced-motion: reduce is enabled.


Scroll navigation becomes instant.


Scroll-reveal elements remain visible.


Particle canvas draws once instead of continuously moving.


Recharts’ JavaScript bar/line animations are not explicitly connected to this setting.

On small screens, the central pipeline node spans both columns; architecture remains two columns. Some navigation items, secondary text, and the GitHub button are hidden to save space.
