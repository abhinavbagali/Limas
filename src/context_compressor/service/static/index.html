Under the hood · 03

Built to keep context connected.

Four composable modules shape sentence selection, preserve discourse dependencies, and measure paired runs.

Python middleware · FastAPI

DiscoursePreserver

coreference.py

Prevents orphaned pronouns by binding dependent sentences to antecedents as atomic blocks.

CrossEncoderRelevanceScorer

scorer.py · models/cross_encoder.py

Calculates batched query-to-sentence relevance scores with contiguous pairwise joint gain.

QueryComplexityGater

gating.py

Dynamically scales relevance thresholds and word budgets based on query intent signals.

Groq & metric logger

groq_client.py · comparison_metrics.py

Uses provider-reported prompt-token usage and appends paired evaluation metrics to Excel.
